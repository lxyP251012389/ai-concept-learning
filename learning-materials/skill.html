2核心问题

  1. 同一个任务，为什么每次都要重新把要求说一遍？能不能"教一次，以后都会"？
  2. Skill 和"保存一段提示词"有什么本质区别？
  3. Skill 是怎么被 AI"学会"的——是训练进模型里，还是别的方式？

3我的解释

我的理解：Skill 就是写给 AI 看的标准作业程序（SOP）手册。你把"这类任务该怎么做"——适用场景、需要什么输入、分几步、每步的规范、最后自检——写成一份结构化文件，放进约定目录。之后只要你提到相关任务，AI 会自动把这本手册翻开（加载进上下文），照着步骤执行。

它最妙的地方在于"教一次，到处复用"：知识不在对话里，而在文件里——于是可以用 Git 管版本、可以分享给同学、可以不断迭代。而且它不改模型本身：模型还是那个模型，Skill 只是在合适的时机把"方法"递到它眼前。这学期这个仓库里的 concept-learner 就是一个活例子：写好之后，无论学"Agent"还是学"RAG"，走的都是同一套流程。

4核心机制 / 组成

一个 Skill 的基本结构

---
name: concept-learner          # 技能名（目录同名）
description: 概念学习资料生成器…… # 触发依据：AI 读它来判断何时使用
---

# 技能标题
## 适用场景    → 什么时候用
## 输入信息    → 调用时要提供什么
## 生成步骤    → 按什么流程做
## 输出结构    → 产出长什么样
## 资料来源要求 → 质量红线（如：禁止编造来源）
## 自检清单    → 交付前逐项核对

关键机制

机制说明
声明式触发Agent 不需要被告知"请用某技能"，而是根据 description 与当前任务的语义匹配度自主决定——所以 description 写得越准，触发越可靠
上下文注入Skill 内容在触发时被放进上下文，与用户输入一起参与推理；不触发时不占窗口空间
项目级 / 用户级放在仓库 .workbuddy/skills/ 的是项目级（团队共享、随仓库走）；放在个人目录的是用户级（跨项目可用）
可组合资源除 SKILL.md 外可附带脚本、模板、参考文件，形成"说明书 + 工具箱"的完整技能包
类比的局限：把 Skill 叫"AI 的技能"容易误解为模型学会了新能力。其实它更接近"给一个聪明实习生发了一份 SOP"——能力（聪明）一直在模型里，Skill 提供的是经验（怎么做这件事）。SOP 写得差，聪明实习生也会做错事。

6概念辨析与使用边界

概念是什么与 Skill 的区别
Prompt（提示词）一次对话里说的话术一次性、易失、难共享；Skill 是结构化、可版本化、可自动触发的任务知识包
Agent（智能体）会规划、用工具、循环干活的执行者Agent 是"人"，Skill 是它手里的"SOP 手册"；同一个 Agent 可挂载任意多个 Skill
工具 / MCP 连接器给模型接的外部能力（搜索、代码执行、数据库）工具解决"能不能做"（能力），Skill 解决"怎么做才对"（方法）；两者常配合：Skill 的步骤里调用工具
微调 / 训练改变模型参数本身Skill 不碰参数，随取随用、随时可撤；微调持久但昂贵、更新慢

常见误解与使用边界

  • 误解："Skill 越多越好。" 不是。Skill 之间的 description 若语义重叠，会互相抢触发、降低可靠性；按需添加、边界写清楚才有效。
  • 误解："写了 Skill 就一劳永逸。" Skill 是经验资产，需要在使用中发现问题、持续修订——这正是把 Skill 放进 Git 仓库管理的意义。
使用边界：① Skill 适合"有稳定套路、会重复发生"的任务；一次性的活直接对话即可，别过度工程化；② Skill 是知识不是能力——步骤里用到工具时，前提是环境里真的接了那些工具；③ Skill 质量直接决定输出质量，自检清单和来源红线这类"约束条款"不能省。

7自测问题

1.（简答）一个 Skill 文件至少要包含哪两部分？各起什么作用？

答：YAML 元数据（name + description，description 是 Agent 判断何时触发的依据）和正文（适用场景、输入、步骤、输出、约束、自检等方法论内容）。

2.（简答）Skill 是怎么被 AI"学会"的？

答：不经过训练。Agent 在任务与 description 语义匹配时，把 SKILL.md 内容加载进上下文，模型据此按步骤执行——是"现场翻手册"，不是"背进脑子"。

3.（简答）项目级 Skill 和用户级 Skill 有什么区别？本作业用的是哪种？

答：项目级放在仓库 .workbuddy/skills/，随仓库共享给所有协作者；用户级放在个人目录，跨项目个人可用。本作业是项目级（方便老师和其他同学直接查看复用）。

4.（选择）"让 AI 能搜索网页"和"教 AI 按固定八板块生成学习资料"，分别对应？
A. 都是 Skill　B. 前者是工具，后者是 Skill　C. 前者是 Skill，后者是工具　D. 都是工具

答：B。搜索是接入外部能力（工具/MCP）；八板块流程是沉淀做事方法（Skill）。Skill 的步骤中往往还会调用工具配合完成。

5.（简答）为什么说 Skill 的 description 是"触发可靠性的生命线"？

答：Agent 是否加载一个 Skill，依据是 description 与当前任务的语义匹配。description 含糊或与其他 Skill 重叠，会导致该触发时不触发、不该触发时乱触发。
